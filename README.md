# 飲料點單管理器

這是一個單檔版的飲料點單小工具，目前內容版本為 **v2.2**。

## 專案結構

- `index.html`：網站首頁，包含完整的 HTML、CSS 與 JavaScript。
- HTML：負責畫面骨架，例如標題列、圖例、進度條與名單容器。
- CSS：負責 macOS 玻璃視窗、卡片及狀態顏色等外觀。
- JavaScript：負責名單資料、點擊切換狀態、統計未點名單及下載 PNG。

## 修改人名或樓層

在 `index.html` 下方的 `<script>` 中修改 `sections` 陣列：

- `label`：分組名稱，例如 `2F`、`中區`、`3F`。
- `people`：人員名單。
- `name`：顯示名稱。
- `sub`：顯示於名稱下方的小字備註。

## 狀態操作

點擊人員卡片時，狀態會依照以下順序循環：

`none` → `done` → `skip` → `leave` → `none`

- `none`：未點
- `done`：已點單
- `skip`：不點
- `leave`：休假

## 版本紀錄

- **v2.0**：第二個正式版本，完成明顯整理、重構或新增一組功能。
- **v2.1**：更新人員名單，移除離職人員並新增新人員。
- **v2.2（目前版本）**：小幅更新人員名單，新增多多（張庭軒）至 2F。
- **v3.0（規劃）**：操作流程、資料結構或主要功能的大幅改版。

網站首頁固定使用標準檔名 `index.html`，版本資訊記錄於本文件；HTML 的 `<title>` 維持簡潔的工具名稱。
